## 记录原则

1. 官方条款优先；第三方内容单独标注，不作为银行承诺。
2. 活动注明查阅日期、有效期、适用卡种、支付渠道、限制与到账时间。
3. 区分已核验规则、待核验观点和本人实测，未实测不写成经验。
4. 用净收益比较：返现减去交易费、换汇成本和增量年费。
5. 不上传卡号、安全码、证件、验证码或个人账单地址。
