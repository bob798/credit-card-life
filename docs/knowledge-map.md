# 知识版图｜跨境金融与数字身份

> 更新：2026-10-20。知识目录，不代表每个金融产品均已核验或开通。

## 六层知识体系

| 层 | 研究对象 | 关键判断 |
|---|---|---|
| 身份与资格 | 国籍、居住地、税务居民身份、KYC、ITIN、SSN、地址证明 | 我是否合法具备申请资格？ |
| 银行与账户 | 招商银行、香港银行、BOG、TBC、OCBC | 谁持有存款？账户归属、币种和保护规则是什么？ |
| 钱包与支付工具 | PayPal、Wise、Starryblu | 余额、收款资料与卡片权限分别是什么？ |
| 支付清算网络 | 银联、Visa、Mastercard、SWIFT、FPS、ACH、SEPA、PayNow | 资金通过什么网络移动？ |
| 费用与权益 | 返现、积分、活动、跨境手续费、汇差 | 净到手/净收益是多少？ |
| 合规与风险 | 资金来源、用途、税务、反洗钱、平台风控 | 是否可持续，失败和冻结如何处理？ |

## 重要区分

- **银行账户 ≠ 银行卡 ≠ 钱包余额 ≠ 本地收款资料**。某平台展示银行名称或账户信息，不意味着用户本人在该银行开户。
- **支付成功 ≠ 可入金 ≠ 可提现**。必须分别验证产品、地区和路径。
- **身份号码 ≠ 居留权 ≠ 信用资格**。ITIN 是美国税务识别号码，不是美国合法居留证明，也不保证美卡获批。
- **账户地区依真实居住情况及监管资格确定**。虚构地址或身份可能违反服务条款。

1. 先看 [谁适合阅读](audience-value.md)，判断研究是否对自己有价值。
2. 通过 [跨境资金流动模型](money-flow.md)确认资金起点、终点、通道及限制。
3. 查看 [研究核验清单](research-backlog.md)辨识尚未确定的事实。
4. 再阅读实际案例：[招行境外返现](../notes/cmb/overseas-unionpay-cashback.md)和[美国信用卡指南](../notes/us/us-credit-card-guide.md)。

## 资料分类标签

- **官方已核验**：附直接官方来源、查询日期、适用条件及有效期。
- **第三方线索**：社区经验、商业文章，尚不足以构成规则。
- **个人实测**：有可重复的步骤与脱敏凭证；单次成功不保证普遍可用。
- **待验证**：假设、计划或未得到明确答复的条件。
